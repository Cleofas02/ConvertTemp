# 🌡️ ConvertTemp

A simple temperature conversion desktop app written in **C#**, used to convert temperatures.

![image](https://github.com/user-attachments/assets/42ff6158-3a7a-437f-b0de-b8bc69b9fc60)

## 📌 Features

- Converts temperatues
- Desktop GUI application

## 🛠️ Tech Stack

- C#
- .NET Framework

## 🚀 Usage

1. Open the project in Visual Studio
2. Build and run
3. Use the dropdown and input field to convert values
